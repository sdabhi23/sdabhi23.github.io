# Writing drafts

Drop unfinished writing here as plain-text files while it's still in progress. When it's ready, turn it into a post by hand: create `content/posts/YYYY-MM-DD-your-slug.md` with

```md
---
title: Your title
description: One-line description for the listing page
---

Your post body, in Markdown.
```

See `blog/README.md` for the full format and how to preview/build.
